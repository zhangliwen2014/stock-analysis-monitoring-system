# SAMS 第三轮实机验收：5 角色反馈汇总（2026-11-03）

日期：2026-11-03（周二，A 股交易日）｜ 输入：5 位角色独立实测回执 ｜ 对照：`2026-10-31-expert-testing-round2.md`、D283

上一轮在周六休市做，问的是「能不能读」；本轮在交易日做，问的是**「按屏上的数做事，敢不敢」**。
约束：全程只走 HTTP，不读源码、不用 CLI；写入限「以 `验收-` 命名的 1–2 条」且用后自删（5 人均已核对删除前后行数一致）。

## 1. 结论先说

| 角色 | 一句话判决 |
| --- | --- |
| 价值投资经理 | **勉强能用** — 且只在少数 A 股大盘白名单上，港股基本不能用 |
| 波段交易员 | **不能用** — 技术面 488/5379 可用，个股页没有一个是数，时点两套 |
| 组合风控 | **不放行** — 报价与日线两个收盘价、超限不告警、静音不可审计 |
| 盯盘散户 | **看情况** — 留存杀手是「让人敲命令行」和「看不出今天哪只有事」 |
| 量化复核 | **需人工复核** — 复权/选股算术全过，「截至日期」类标注不可直接信 |

五人独立报出、且互相印证的只有一件好事：**数字本身算得对**（复权、PB、MA20、选股计数全部闭合）。
所有 P0 都集中在**「同一件事在两个地方有两个说法」**：两个价、两个日期、两个基准、两个收盘。

统计：31 条，P0 8、P1 16、P2 7；多源（≥2 人）14 条。
