# 产品平台差距分析与功能强化方案（SAMS）

日期：2026-10-31 ｜ 角色：产品负责人 ｜ 输入：竞品调研记录、R-01…R-27 实机验收、D232 能力评审、代码审计现状
范围：只做产品与数据方案，不改代码、不提交。现状列只引用既有审计，不新增代码判断。

## 1. 结论摘要

1. **三支柱差的不是功能数量，是「一个口径 + 一条证据链 + 一次自动复检」。** 竞品调研对选股/估值线的粗判是数据缺口约六成、交互约四成（tradingview.com、support.futunn.com、help.sharesight.com）。
2. **选股：条件够，解释不够。** 23 字段、6 算子、预设保存已可用；缺的是命中原因回显、ST/退市与负值护栏、技术面字段、新命中提醒。舆情字段在无源之前不应上线。
3. **买卖评估是最高杠杆的新增。** 论点、规则、估值、假设都已存在，但没有一张卡把「入场区间 / 止损 / 目标 / 赔率 / 胜率 / 证据 / as-of / 结论」放在一起，用户仍要自己拼。
4. **监控告警：底子是优势，缺证据与节制。** 14 类规则、6 通道、状态机（已读/稍后/处置/驳回+原因码）、证伪台账都是领先项；缺触发 bar、去重键、证据链接、每日摘要。
5. **自动化要「少而准」。** 已有日/周/月 job 与连续 3 周期失败告警；补「自选∪持仓日更 + 变化才告警 + 一条摘要」即可，不做全市场逐票深挖。
6. **基本面深度是「研究页」缺口。** F10 有资料、公告、五年指标、分红，但没有核心业务、行业地位、同业与估值对比；行业映射是分位与同业的共同前置。
7. **两周内先做三件：** 一价一 as-of（止血）、决策卡（回答买卖）、每日变化摘要 v0（自动化感知）。
8. **明确不做：** 下单、社区、实时 tick、情绪分、DCF 单一目标价、5900 条件平台。

## 2. 目标与判据

北极星（用户原话）：

> 1、选股：根据 基本面、技术面、舆情等，选择股票
> 2、买卖评估：股票的买入时机和价格、卖出时机和价格、赔率、胜率
> 3、监控和告警：比如是否到达买入的时机和价格、卖出的时机和价格、基本面有什么变化、有什么和其相关的舆情
> 核心就是完善这些能力，形成功能，并把这些自动化。这些应该是核心的竞争力
> 1、自选股、持仓股等，可以设置 自动持续 监控、分析、完善 信息的功能
> 2、查看股票的基本面，不仅有基础信息，还有公司的核心业务、该核心业务在行业中的地位、行业的趋势，同类公司和上市公司的情况、估值对比等

| 能力 | 可验证的用户任务 | 判据 |
| --- | --- | --- |
| 选股 | 3 分钟得到「ROE>15%、PE<20、非 ST」的 A 股名单 | 每只票可展开命中字段/阈值/实际值/as-of；能答出通过、不通过、无数据各多少 |
| 买卖评估 | **3 分钟内回答「这只票现在该不该买、买多少、错了在哪走」** | 卡片同时给入场区间、止损、目标、赔率、胜率或「样本不足」、证据、as-of、结论 |
| 监控告警 | 收盘后收到一条只含变化的摘要，点开回到触发 K 线 | 无变化不打扰；同一事件重跑不重复告警；源失败显示「数据未更新」 |

## 5. 目标能力蓝图

### 5.1 选股三层与可解释结果

- **L1 基本面**：沿用 23 字段，先加三道护栏——PE/PB/PS 类默认 `positive_only`，亏损标「亏损」排末尾；ST/退市默认排除并在页头写明排除数；非法值返回 400 带中文字段名，不静默直出。
- **L2 技术面**：MA20/60/250、RSI14、量比（5 日均量）、52 周位置，全部读取层派生，不新增原始表。样本不足 250 根显示「—」且**不参与筛选**（空≠不满足）。HK/US 以 bars 链修通为前置。
- **L3 舆情**：在无可靠源前，这一层只做「公告/新闻关键词命中」，不做情绪分。无源时整层灰显「未接入」，沿用市场能力矩阵的诚实口径。
- **结果可解释**：每行可展开「命中原因 / 未命中原因 / 样本数（通过·不通过·无数据）/ as-of」；as-of 条抽成全站组件，不逐页拼日期。
- **新命中**：预设记录 `last_run_at` 与首命中时间，只报窗口内首次命中，按 `(preset, market, code)` 去重；默认日频盘后，可切周频。

### 5.2 买卖评估「决策卡」

一张卡固定 10 个格子：标的与市场 / 数据 as-of / 现价（含来源与价格种类）/ 入场区间 / 止损 / 目标 / 赔率 / 胜率（含样本）/ 证据清单 / 结论。三价与结论存入 `thesis_plan(thesis_id, entry_low, entry_high, stop, target, method, as_of, version)`，版本化留痕。

**三价与公式。** 入场区间 `[P_low, P_high]` 必须有方法标签（估值下沿、技术支撑、人工）；止损 `S` 必须低于入场，依据为「论点失效价 / 前低-ATR 缓冲 / 固定比例（默认 8%，上限 15%）」；目标 `T` 来自估值中枢或前高。以入场中值 `P` 计：

- 赔率 `R = (T − P) / (P − S)`。守卫：`P > S > 0`、`T > P`；`R < 1` 标「赔率不足」；`R > 10` 显示「>10」，不报三位小数。
- 胜率 `p` = 同市场、同规则、同参数、同持有窗口的历史触发样本中「目标先于止损触达」的比例，同一 bar 同时触达按止损先算（保守）。样本守卫：`n < 30` **只显示「样本不足」，不给百分比**；`30 ≤ n < 100` 给 Wilson 95% 区间并标「低置信」；`n ≥ 100` 给点估计+区间。必须显示样本数、起止日、市场、规则版本，样本含退市与停牌，禁止未来函数。
- 期望 `EV_R = p × R − (1 − p)`；仓位上限 `f = p − (1 − p) / R`，取 1/4 后分档（0、≤3%、≤5%、≤10%），再受单票上限约束。**无止损或样本不足不出仓位。**

**结论三态。** 回避：论点被证伪、价格高于目标、或 `R<1`（赔率不足）；观察：价格未进入区间、样本不足、数据过期（报价超 5 个交易日或财务超 1 个报告期）；分批：价格进入区间、`R ≥ 2`、样本达标、无证伪、未触组合上限。展示口径：只给区间不给单一目标价，不用「买入」祈使句，每个数字带来源与 as-of，样本不足绝不显示概率。

### 5.3 监控与告警

- **日更范围**：自选 ∪ 持仓，市场收盘后依次跑报价、基本面（新财报/指标越阈值）、公告/新闻命中、假设复核、规则；论点标的沿用既有 universe。
- **变化才告警**：规则用 `hash(rule_version, symbol, bar_ts, state)` 作去重键，只在状态跃迁时发；假设用 `(assumption_id, evaluated_period, value)`；公告用 `(symbol, announcement_id)`。重跑必须 0 新增。
- **每日摘要**：每用户每市场每日 1 条，18:30 本地时间，分「持仓 / 自选 / 观察」三栏，只列变化；无变化也发一句「今日无变化」，让用户知道系统活着。这一条是自动化最便宜的感知入口。
- **证据链**：告警带 `trigger_bar_ts`、触发时价格与指标值、规则版本、可复现链接（`/rules/{id}/check?as_of=…`）；告警详情加「触发记录」页签，处置理由进统计。
- **静音/分组**：按标的、规则、市场分组；静音仍落库不投递；支持批量已读并留痕。
- **失败降级**：单源失败标「数据未更新（原因）」，不得写成「无变化」；连续 3 周期失败沿用系统告警；摘要标注覆盖只数与缺失市场。

### 5.4 基本面深度

| 维度 | 内容 | 路径与标签 |
| --- | --- | --- |
| 核心业务 | 主营构成、收入拆分、客户与产能 | 年报/招股书文本：**公开源可做**（需抽取），v1 先**需人工录入** |
| 行业地位 | 市占率、排名 | 协会/付费库：**需付费**；替代用营收规模分位，标「代理指标」 |
| 行业趋势 | 增速、渗透率、政策 | 统计局/协会：**公开源可做**（人工整理）；深度研报**需付费** |
| 同业公司 | 3–5 家同业与财务对比 | A 股**公开源可做**；HK/US 的 GICS 与一致预期**需付费** |
| 估值对比 | 同业中位 PE/PB/ROE/股息率 + 自身 5 年分位 | A **公开源可做**；HK/US 补历史后做 |
| 自动 DCF 主结论 | 单一内在价值 | **不做**（伪精度），只作区间与敏感性表 |

缺失统一四级：不适用 / 未披露 / 无法计算 / 未覆盖，行级「—」加悬浮原因，不补零。

## 10. 专家评审问题

1. **默认价格口径**：A 收盘优先，盘中显式切「实时」；B 盘中优先，收盘作副行。倾向 A——Web 不是交易终端，冻结快照最易被误读。
2. **决策卡是否给仓位数字**：A 只给分档（0/≤3%/≤5%/≤10%）；B 给精确百分比。倾向 A，精确到小数会把公式误差包装成确定性。
3. **胜率口径**：A 同规则同参数的历史触发样本；B 全市场同类形态基础率。倾向 A，B 只作先验收缩，且两者都必须显示样本数。
4. **舆情落地方式**：A 先做公告/新闻入库+关键词+原文链接+as-of；B 直接接第三方情绪分。倾向 A；B 只有在能给出逐条可复核依据时才考虑。
5. **新命中频率**：A 日频盘后；B 周频（SWS 口径）。倾向 A，数据与算力都现成，但默认只发新增、可切周。
6. **组合 NAV 起点**：A 从成交完整之日起算，之前标「不完整」；B 用当前持仓倒推历史。倾向 A，倒推等于编造历史净值。
7. **港美优先级**：A 先港（已有持仓与估值注册）；B 先美（搜索与概况缺口更大）。倾向 A，先用持仓验证链路，再扩美股。

### 11.1 决策卡（替代 §5.2 的 10 格版本）

v0 只做 6 格：**标的状态 / 现价与价值区间位置 / 失效价 / 目标区间 / 赔率区间 / 结论 + 3 条证据**。as-of 附在每个数字旁。

- 结论改四态 + 持仓侧：未持仓 `不追 / 等价格 / 证据不足 / 可分批建仓`；持仓 `持有 / 减仓 / 退出`。优先级：证伪 > 止损触达 > 数据或样本不足 > 价格区间。「价格高于目标」叫「不追」，不是标的变差。
- 赔率给区间并扣成本：`R_low=(T−P_high−c)/(P_high−S+c)`，`R_high` 用 `P_low`；T 与 S 方法标签必须不同源；分批要求 `R_low≥2`；成本 A 0.3% / HK 0.6% / US 0.2%；跳空按 `min(S, 开盘)`；止损距离 `< max(3%, 1×ATR14)` 判「止损过近，R 无效」。
- 胜率 v0 **不上卡**：A 股仅 121 根日线，n<30 恒成立。后续按「参数冻结 + walk-forward + 独立波段冷却」实现；n≥30 且独立波段≥15 才给百分比，EV/凯利用 Wilson 下限；缺退市样本须披露幸存者偏差。
- 硬闸：bars 为空或 <300 根、报价超期（A/HK 3 个交易日、US 2）、财务超期（A 120 天 / HK 200 / US 100）时只出「数据不足，不出结论」，禁 R/胜率/仓位。
- 仓位只给「数学上限，非建议」分档（0/≤3%/≤5%/≤10%），并显示金额与跌破失效价的亏损额；禁精确百分比/股数、单一目标价、单一 R、买入祈使句。
- 港美先出**降级卡**（现价/失效价/事件，无估值区间），明示缺什么；港美数据链修通后再升级。
