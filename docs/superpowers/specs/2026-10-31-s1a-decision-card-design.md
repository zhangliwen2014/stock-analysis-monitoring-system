# S1-A 决策卡 v0（A 股）设计

> 依据：`2026-10-31-expert-review.md` 第 2–6 条与 `2026-10-31-product-platform-gap-analysis.md` §11.1。
> 目标：个股页用一张 6 格卡回答「此刻该不该动手」，每个数字带来源与 as-of；数据不足时只出
> 「数据不足，不出结论」，不拿半个计划冒充结论。

## 1. 卡面（6 格 + 3 条证据）

| 格 | 内容 | as-of / 来源 |
| --- | --- | --- |
| 标的状态 | 是否持仓（股数、均价、账户）、是否自选、有没有活的论点、论点状态、已证伪的假设 | 最近成交 / 论点更新时间 |
| 现价与价值区间位置 | 现价（盘中/收盘/旧价）、合理区间、现价在区间内/上方/下方多少 | 报价标签 + 估值读数日 |
| 失效价 | 买入口径或持仓口径的止损、方法标签、距现价多少、是否「止损过近」 | 估值读数日 / 论点 levels_on |
| 目标区间 | 合理上限与前高，较近的一端计入 R，现价距两端多少 | 估值读数日 |
| 赔率区间 | `R_low ~ R_high`、成本、买入区、无效原因 | 估值读数日 |
| 结论 | 四态 + 持仓侧三态，附一句理由 | 与各格同一 as-of |

三条证据固定为「价格 / 价值 / 风险」，每条带 `来源 · as-of`。证据不是复述数字，而是让读的人
能追到那个数出自哪条链（报价源、PR 口径、止损式子）。

## 2. 硬闸（先于一切结论）

| 闸 | 判定 | 失败时 |
| --- | --- | --- |
| 日线 | `bars.count(A, code) >= 300` | 只出「数据不足，不出结论」 |
| 报价 | A/HK 报价日距今 ≤ 3 个交易日，US ≤ 2 | 同上 |
| 财务（仅 A 股估值链） | 最新一期已披露财报（含半年报/季报）距今 ≤ 120 天 | 同上 |

- 任一硬闸失败：`data_ok = False`，止损/目标/赔率全部留空，禁 R/胜率/仓位。
- 交易日按市场本地日历数；日历未覆盖的那一天按工作日保守计。
- 财务新鲜度取 `max(published_on, interim_published_on)`：ROE 仍按年报口径用于 PR，
  但「有没有新财报」看的是最新披露的那一期，否则一份八月发的中报会被年报的发布日期误判超期。
- 港美不出估值链，**不套财务闸**；日线与报价两闸照旧。

## 3. 买入口径与持仓口径

同一张卡对未持仓与持仓回答两个不同的问题，风险锚点因此不同，且屏幕上写明是哪一种：

- **未持仓（买入口径）**：现价只用来判断「到没到买入区」。止损按**买入区中值**用模板的止损
  方法重算（`pct` / `atr2`），因为模板里的止损是按当前价算的——现价高于买入区时，
  那个止损会落在买入区之上，拿它算 R 会得到负分母。`weekly_ma20` / `fixed` 不重算；
  若它们不低于买入区下沿，直接判「止损不低于买入区，R 无效」。
- **持仓（持仓口径）**：止损用计划里按现价算的那一档（没有就用论点存的 `stop_price`），
  它才是这笔仓位真正的失效价；R 以现价单点计算，不再给买入区区间。

目标区间两口径相同：合理上限与前高，较近的一端 `T_low` 计入 R。未持仓时只把高于买入区中值
的候选计入（目标是「买入之后往上到哪」）；持仓时不按现价过滤，因为现价越过目标正是「减仓」
的信号。

## 4. 赔率区间

成本 `c(price) = cost_pct × price`，`cost_pct`：A 0.3% / HK 0.6% / US 0.2%（买卖合计的保守口径）。

```
R_low  = (T_low − P_high − c(P_high)) / (P_high − S + c(P_high))
R_high = (T_low − P_low  − c(P_low))  / (P_low  − S + c(P_low))
```

- `P_low/P_high` 是买入区两端（未持仓）或现价单点（持仓）。
- 无效条件：`S <= 0`、`S >= P_low`、`T_low <= P_high`、`R_low <= 0`、止损距离
  `< max(3% × 参考价, 1 × ATR14)`。止损距离那一条的理由固定写成「止损过近，R 无效」。
- `R_low >= 2` 才允许「可分批建仓」；`R_low < 2` 时未持仓只说「等价格」。
- 显示保留一位小数；超过 10 写「>10」。

## 5. 结论与优先级

优先级从高到低，前一条命中就不再往下看：

| # | 条件 | 未持仓 | 持仓 |
| --- | --- | --- | --- |
| 1 | 硬闸失败 / 关键价位缺失 | 证据不足 | 证据不足 |
| 2 | 论点假设被证伪 | 不追 | 退出 |
| 3 | 现价 ≤ 失效价 | 不追 | 退出 |
| 4 | 现价 ≥ 目标下沿 | 不追（价格高于目标，不等于标的变差） | 减仓 |
| 5 | 价格在买入区且 `R_low >= 2` | 可分批建仓 | 持有 |
| 6 | 价格在买入区但 `R_low < 2` | 等价格 | 持有 |
| 7 | 价格未到买入区 | 等价格 | 持有 |

- 持仓侧在没有止损或没有目标时归「证据不足」，不拿「持有」替一个不知道何时退出的仓位背书。
- 证伪优先于价格：价格在买入区 + 证伪，输出「不追/退出」，绝不输出「可分批建仓」。
- 不用「买入」祈使句；仓位与胜率 v0 不上卡。

## 6. 港美降级卡

港美先出降级卡：现价、论点里的失效价/目标（若有）、最近告警；估值区间与 R 明说「缺估值链」。
未持仓一律「证据不足」；持仓在止损/目标未触达时「持有」，触达时「退出/减仓」。
日线与报价两闸仍然生效。

## 7. 复用与落库

- 价位复用 `theses` 的 `entry_low/entry_high/stop_price/target_price/reward_risk`，不建
  `thesis_plan` 表。
- 迁移 `0033` 只加两列可空列：`theses.plan_version`、`theses.plan_method`。
  `plan_version` 写 `decision-v0`；`plan_method` 存 JSON（止损/入场/目标/口径/as_of），
  供详情页与以后的版本对比。手填价位不写方法标签。
- 卡本身每次按今天的库重算，不依赖历史快照；两列元数据只回答「这条论当时是按哪套方法落的数」。

## 8. 页面与入口

- 个股页 `#decision`，放在行情卡之后、图表/资料之前；六格 + 结论条 + 三条证据。
- 持仓页每一行代码旁加「决策」链接，直达 `/symbol/{market}/{code}#decision`。
- 返回到选股列表仍走既有 `back` 参数，不改 S0 的返回链路。

## 9. 验收

1. 任一 A 股持仓在 3 分钟内给出四态之一，且每个数字旁有来源与 as-of。
2. 空 bars / 少于 300 根：只出「数据不足，不出结论」，R、止损、目标留空。
3. 财务超期、报价超期各自点名是哪一道闸，不混成一句「没数据」。
4. 证伪 + 价格在区间：输出不追/退出，不输出可分批。
5. 港美：降级卡明说缺估值链，不假装有 R。
6. ruff 通过、全量测试通过、服务实机可打开卡片。

## 10. 非目标（v0 明确不做）

- 胜率、精确仓位、EV/凯利：样本不足（A 股 121 根日线，n<30 恒成立）。
- 港美估值链修复与同业估值对比。
- 自动下单或任何交易动作。
