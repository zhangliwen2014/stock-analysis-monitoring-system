# M3-C 规则引擎 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 spec §10 的规则体系落成能跑的一层——规则入库、模板纯求值、三级触发、冷却去重、命中后经 M3-B 那条路投递出去，并补上 §9.2 的建仓派生规则与 §9.3 的周复检。

**Architecture:** 三层各管一件事，边界由分层守卫钉住：`core/rules.py` 只有词汇（模板名单、参数表、阶段、`Verdict`），`storage/repos/rules.py` 只有写入与修订史，求值与装配在 `services/rules/`（纯函数模板 + 一份取数装配 + 一趟引擎）。引擎**不认识** `monitor`：投递是一个注入的端口（`core/notify.py::AlertSender`），`bootstrap` 把 `NotifyService.dispatch` 接上去——这是 D93 已经验证过的形状（`HealthService` 收 `local_status` 而不是 import `monitor`）。

**Tech Stack:** Python 3.13、DuckDB、Polars、pytest；无新第三方依赖（`GATED` 名单不变）。

## 1. 这一层要防的是哪一类错

这一层的错**全部长成「屏幕上看着正常」的样子**，所以每个任务的测试断言写的都是「这里必须是这句话」，不是「这里不崩」：

| 错法 | 屏幕上什么样 | 真实的代价 |
|---|---|---|
| 除权日误报跌破止损 | 一条完全合理的「止损已破，请立即处置」 | 用户在一次分红那天被指挥去卖一笔没亏的仓（§10.2 的强制验收用例） |
| 冷却把升级吞掉 | 「已压制」，库里那一行写着 cooldown | `pre` 报了之后 30 分钟内的 `hit`（真跌破）没人听见——冷却是给降噪用的，不是给止损用的（D94） |
| 跨账户互相覆盖 | 只有一条告警 | 同一只票两个账户不同成本，A 触发后 B 的破位被当成重复丢掉（§10.1 的去重键含 `account_id`） |
| 周复检把「从没比过」说成「没漂移」 | 「观点未漂移」 | 基线没建立时那是一句没人验证过的谎（D96） |
| 阈值没带币种 | `止损 100` | A 股是元、美股是美元；§5.4 规则 3 禁止未标注币种的金额 |
| 规则的 `channel_ids` 指向别人的通道 | 发出去了，发到别人群里 | 归属必须在服务层核过一次，仓库只保证「这条通道属于这个用户」 |

## 3. 这一轮明确不做什么（写下来才不算漏）

spec §10.3 自己说了「40 个是能力目录，不是 M3 的实现承诺。M3 只实现被真实使用验证过的子集」。裁剪：

- **`market_rel` 过滤器不做**：它要一个指数序列（沪深300），而 `bars` 里没有指数、采集链也没有指数端点。`validate_filters` 会点名「`market_rel` 没有输入」。指数数据记为 U27。
- **`cli rules replay` 不做**：重放是回测的前置（M5）。这一轮只给 `sams rule check --as-of <日>`——它按那一天重算**判断**，不重放事件流，也不改冷却状态（冷却只读 `alerts`，`--as-of` 那趟不落库除非真发）。
- **组合级指标不做**（仓位占比、当日盈亏、最大回撤、板块集中度，§10.1 末段）：后三项需要每日组合快照，而库里没有那张表。持仓类规则这一轮只吃 `PortfolioService.positions` 已有的数。记为 U28。
- **盘中轮询不做**：`QuoteUpdated` 没有生产者（M3-D 的调度器才有）。`sams rule check` 是**同步一趟**，吃日线收盘。`urgent`（跳空低开破位）因此只能按当日**开盘价 vs 前收盘**判，报出来的时刻是收盘后——这一点在 §10.2 的验收里必须写清楚，M3-D 接上快照源后同一个判据会自己变早。
- **`condition_kind='expression'` 不做**（M5），`condition_kind` 列恒为 `'template'`，仓库层拒收别的值。
- **§10.3 表里其余 ~27 个价格/指标/量能模板不做**：九个止损止盈（§10.2 点名的专项）+ 四个 §9.2 派生 kind 已经覆盖「建仓 → 持有 → 了结」这条主线，剩下的等 M3-D 挂机跑一个真实交易日之后按真实使用量补。

- **模板表住在 `core`**，因为三处都要读它而三处互相不许 import：`storage/repos/rules.py` 要在写入前校验 `kind`/`params`（`storage` 只许 import `core`）、`services/rules/templates.py` 按它求值、`cli/rule.py` 按它解释参数并打印帮助。把名单写进 `services` 就等于让仓库层够不着它——仓库够不着校验，垃圾就能进库（M3-B 的 `KINDS` 是同一个决定的另一处落点，见 D92 的注释）。

```python
"""规则的词汇表：模板名单、参数表、阶段、过滤开关、判定形状（spec §10）。

和 `core/notify.py` 同一个理由：**不含 IO**。仓库层要按它校验写入、求值层按它取默认值、
命令行按它解释参数与打印帮助，三层都能引用而互不 import。名单一旦写进 `services`，
`storage` 就够不着它——够不着校验的名单等于没有名单，垃圾能直接进库。
"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any

from sams.core.errors import ValidationError

#: 三级触发（§10.2）。`pre` 是「快到了」，`hit` 是「破了」，`urgent` 是「跳空破的」。
STAGES = ("pre", "hit", "urgent")
PRE, HIT, URGENT = STAGES
#: 升级次序。它是「这次命中该不该被冷却吞掉」的判据（D94），所以只能有一处。
#: 不要拿字符串比：`"pre" < "hit"` 是字典序，跟语义正好相反。
STAGE_RANK = {PRE: 0, HIT: 1, URGENT: 2}

#: 规则挂在什么对象上。`target_ref` 的形状按类型定死，见 `storage/repos/rules.py`。
TARGET_TYPES = ("symbol", "watchlist", "thesis", "position", "portfolio")

#: 周复检「掉一档」的那一档有多大（§9.3 说的是「下滑超过一档」，而分是 0~100）。
#: 20 分切成五档是这一层的决定，不是分析层的：分项分的刻度只有 M2-D 那一张表知道，
#: 而「掉一档」必须是一个能复算的数，不能是排版上的形容词。
DRIFT_TIER = 20.0

#: `time_window` 那个开关的窗口：开盘后 5 分钟内不推价格类（集合竞价噪音，§10.1）
FILTER_MINUTES = 5
#: `data_freshness` 认的行情日落后天数。3 个日历日盖住一个周末 + 一天的数据延迟，
#: 再长就该由 `exclude_halt` 或健康页说话，而不是让规则拿三天前的价报「跌破止损」
STALE_PRICE_DAYS = 3

#: 四个可组合开关。`market_rel` **不在这里**：它要指数序列，而这一层没有那个输入（U27）。
FILTER_KEYS = ("time_window", "data_freshness", "exclude_halt", "no_open_alert")


@dataclass(frozen=True)
class Param:
    """模板要的一个参数。`shape` 只有三种：数、枚举、分档串。"""

    name: str
    label: str
    shape: str = "number"
    default: Any = None
    required: bool = False
    minimum: float | None = None
    maximum: float | None = None
    choices: tuple[str, ...] = ()
    unit: str = ""

    def describe(self) -> str:
        tail = f"，默认 {self.default}" if not self.required else "，必填"
        bounds = ""
        if self.minimum is not None and self.maximum is not None:
            bounds = f"（{self.minimum:g}~{self.maximum:g}{self.unit}）"
        elif self.minimum is not None:
            bounds = f"（> {self.minimum:g}{self.unit}）"
        if self.choices:
            return f"{self.name}={self.label}{'/'.join(self.choices)}{tail}"
        return f"{self.name}={self.label}{bounds}{tail}"


@dataclass(frozen=True)
class Template:
    """一个 kind 的形状：要哪些参数、默认什么级别、会不会出三档、挂在什么对象上。"""

    kind: str
    label: str
    params: tuple[Param, ...] = ()
    severity: str = "mid"
    #: 会产出 pre/hit/urgent 三档（只有止损类会：其余 kind 一次命中就是一件事）
    stages: bool = False
    #: 必须挂账户（去重键含 `account_id` 的那一类，§10.1）
    needs_position: bool = False
    #: 必须挂一条论（读它的价位/赔率/分项）
    needs_thesis: bool = False
    #: 价格类：开盘 5 分钟那条过滤器只作用于它们
    price_class: bool = True
    #: 允许的 target_type（写成元组而不是全放开：一条 `stop.pct` 挂在整个自选股清单上
    #: 会读成「每个账户的每笔持仓」，而它得先知道自己挂的是谁的仓）
    targets: tuple[str, ...] = TARGET_TYPES

    def describe(self) -> str:
        parts = [p.describe() for p in self.params]
        return f"{self.kind}（{self.label}）：" + ("；".join(parts) if parts else "无参数")


def _number(name: str, label: str, *, default=None, required=False, minimum=None,
            maximum=None, unit: str = "") -> Param:
    return Param(name=name, label=label, shape="number", default=default, required=required,
                 minimum=minimum, maximum=maximum, unit=unit)


def _choice(name: str, label: str, choices: tuple[str, ...], default: str) -> Param:
    return Param(name=name, label=label, shape="choice", default=default, choices=choices)


#: 每个 kind 一行。`stop.*` 的严重级别都是 strong：止损是「现在就要动」的事，
#: 把它配成 mid 就等于让默认路由绕开语音通道（§11 的 DEFAULT_ROUTE）。
TEMPLATES: dict[str, Template] = {

RULE_KINDS = tuple(TEMPLATES)


def template_for(kind: str) -> Template:
    try:
        return TEMPLATES[kind]
    except KeyError:
        raise ValidationError(
            f"未知规则类型 kind={kind!r}：只有 {', '.join(RULE_KINDS)}。"
            "名单的唯一出处是 `core/rules.py`，加一种就是在这里加一行"
        ) from None


def _as_number(param: Param, raw: object) -> float:
    try:
        value = float(raw)  # 接受 "8"，不接受 "八"：后者抛 ValueError
    except (TypeError, ValueError):
        raise ValidationError(
            f"{param.name} 要的是数字（{param.label}），收到 {raw!r}"
        ) from None
    if param.minimum is not None and value < param.minimum:
        raise ValidationError(f"{param.name} 不能低于 {param.minimum:g}{param.unit}（收到 {value:g}）")
    if param.maximum is not None and value > param.maximum:
        raise ValidationError(f"{param.name} 不能高于 {param.maximum:g}{param.unit}（收到 {value:g}）")
    return value


def _as_tiers(param: Param, raw: object) -> list[float]:
    text = param.default if raw is None else raw
    if isinstance(text, (int, float)):
        raise ValidationError(f"{param.name} 要的是比例串（例如 0.5,1.0），收到 {raw!r}")
    parts = [piece.strip() for piece in str(text).replace("，", ",").split(",") if piece.strip()]
    if not parts:
        raise ValidationError(f"{param.name} 不能是空的：至少给一档")
    steps: list[float] = []
    for piece in parts:
        try:
            steps.append(float(piece))
        except ValueError:
            raise ValidationError(
                f"{param.name} 里 {piece!r} 不是数字：要的是 0.5,1.0 这种比例串"
            ) from None
    if any(step <= 0 for step in steps):
        raise ValidationError(f"{param.name} 的每一档都要大于 0（收到 {steps}）")
    if any(b <= a for a, b in zip(steps, steps[1:])):
        raise ValidationError(
            f"{param.name} 必须递增（收到 {steps}）：1.0 那一档就是「到了目标价」，"
            "排在 0.5 前面会让第一档永远不报"
        )
    return steps


def validate_params(kind: str, raw: Mapping[str, object] | None) -> dict[str, object]:
    """补默认值 + 校形状 + 拒收野键。返回的字典可以直接进 `params_json`。

    「静默丢掉一个不认识的键」是这一层最便宜也最坏的错：用户以为写了 `percent=8`，
    库里那条规则用的还是默认的 `pct`，屏幕上两条都显示「止损比例」——没有任何一处会报错，
    直到那一次没跌破他以为的那条线。
    """
    built = template_for(kind)
    given = dict(raw or {})
    out: dict[str, object] = {}
    for param in built.params:
        if param.name not in given:
            if param.required:
                raise ValidationError(
                    f"{kind} 少了必填参数 {param.name}（{param.label}）：{built.describe()}"
                )
            out[param.name] = _default_for(param)
            continue
        value = given.pop(param.name)
        if value is None and param.required:
            raise ValidationError(f"{kind} 的参数 {param.name} 是必填的（{param.label}）")
        out[param.name] = _default_for(param) if value is None else _coerce(param, value)
    if given:
        raise ValidationError(
            f"{kind} 不认这些参数：{', '.join(sorted(given))}。"
            f"这一种要的是：{built.describe()}"
        )
    return out


def _coerce(param: Param, value: object) -> object:
    if param.shape == "choice":
        text = str(value).strip()
        if text not in param.choices:
            raise ValidationError(
                f"{param.name} 只能是 {'/'.join(param.choices)}（收到 {text!r}）"
            )
        return text
    if param.shape == "tiers":
        return _as_tiers(param, value)
    return _as_number(param, value)


def _default_for(param: Param) -> object:
    return _coerce(param, param.default) if param.shape == "tiers" else param.default


def validate_filters(raw: Mapping[str, object] | None) -> dict[str, bool]:
    """四个开关全给默认值 `False`：默认不降噪，因为「一条静默的规则」比「一条吵的规则」难查。"""
    given = dict(raw or {})
    if "market_rel" in given:
        raise ValidationError(
            "过滤器 market_rel 这一层没有输入：它要比对的指数（沪深300 等）不在库里，"
            "采集链也没有指数端点。给了也不会生效，所以这里直接拒收（记 U27）。"
        )
    out: dict[str, bool] = {}
    for key in FILTER_KEYS:
        value = given.pop(key, False)
        if value is True or value is False:
            out[key] = value
        else:
            raise ValidationError(f"过滤器 {key} 要的是真或假，收到 {value!r}")
    if given:
        raise ValidationError(
            f"不认这些过滤器：{', '.join(sorted(given))}。可用的只有 {', '.join(FILTER_KEYS)}"
        )
    return out


@dataclass(frozen=True)
class Verdict:
    """一次判定的结果。文本与数值**同时带**：文本给人，数值给 `--json` 与复算。

    只给文本的话，机器读者只能去 parse「9.80 元」；只给数值的话，屏幕上那句话就得由
    每个显示层各自拼一遍——§5.4 规则 3（币种口径）会在某一个「各自」里丢掉。
    """

    stage: str
    value: float | None
    threshold: float | None
    value_text: str
    threshold_text: str
    #: 线是怎么算出来的那句话（折回因子、基准是哪天、缺了哪一路），进告警正文
    why: str = ""

    def __post_init__(self) -> None:
        if self.stage not in STAGES:
            raise ValidationError(
                f"未知阶段 stage={self.stage!r}：只有 {list(STAGES)}，"
                "冷却放行按这三个值的次序判（D94）"
            )

    @property
    def ok(self) -> bool:
        return self.value is not None and self.threshold is not None


def tier_of(score: float | None) -> int | None:
    """分项分落在第几档（0~5）。None 进 None：「没这个数」不能排进任何一档。

    §9.3 说的是「下滑超过一档」，而这里的「一档」由 `DRIFT_TIER` 定死成 20 分。
    写成档位而不是分数差，是为了让「78 → 61」这种没跨档的波动**不**报警：
    分项分本身带着窗口噪声，跨档才是能被说清的变化。
    """
    if score is None:
        return None
    return int(max(0.0, min(DRIFT_TIER * 5.0, score)) // DRIFT_TIER)


def escalates(from_stage: str | None, to_stage: str) -> bool:
    """这一次命中该不该穿过冷却（D94）。

    没有上一次 ⇒ 放行。有上一次 ⇒ 只有**更响**的那一档才放行：`pre` 报了 30 分钟内
    再来一条 `pre` 是噪音，而 `hit` 是另一件事——止损真破了。
    """
    if from_stage is None:
        return True
    try:
        return STAGE_RANK[to_stage] > STAGE_RANK[from_stage]
    except KeyError as exc:
        raise ValidationError(f"未知阶段 {exc.args[0]!r}") from None
```

  `escalates` 的异常分支在这里像过度设计（调用方给的都是 `Verdict.stage`，已经过 `__post_init__`），留着是因为它是那张表唯一的读入口：下一次有人往 `STAGES` 里加一档而忘了加 rank，红在这里比红在「止损被冷却吞了」那一天的用户屏幕上便宜。

```python
"""`rules` 与 `rule_revisions`（spec §10.1、§9.2、§4.2）。

这两张表从 `0001` 就在库里而一个写入方都没有。校验因此**全放在仓库层**：
M3-D 的派生写入方与 M4 的后台都不经过 `services`，挡在服务层的约束对它们是空的（D81）。
"""

from __future__ import annotations

import json
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from datetime import datetime

from sams.core.clock import SYSTEM_CLOCK, Clock
from sams.core.errors import StorageError, ValidationError
from sams.core.notify import SEVERITIES

#: 只有这一种条件（§10.4：`expression` 是 M5 的事）
CONDITION_KIND = "template"

_COLUMNS = (
    "id, user_id, account_id, name, enabled, target_type, target_ref, kind,"
    " condition_kind, params_json, filters_json, cooldown_min, severity, channel_ids,"
    " thesis_id, created_at, updated_at"
)

#: 这些 target 的 `target_ref` 恒为「整个集合」，写法里带上 `*` 是为了让它可断言
#: （空串会展开成零个目标，那条规则从此静默不响，而屏幕上它看着是启用的）
_WILDCARD_TARGETS = ("watchlist", "position", "portfolio")


@dataclass(frozen=True)
class Rule:
    id: str
    user_id: str
    name: str
    kind: str
    enabled: bool
    target_type: str
    target_ref: str
    params: dict
    filters: dict
    cooldown_min: int
    severity: str
    channel_ids: list[str]
    account_id: str | None = None
    thesis_id: str | None = None
    condition_kind: str = CONDITION_KIND
    created_at: datetime | None = None
    updated_at: datetime | None = None

    @property
    def describe(self) -> str:
        """一行说得清这条规则在等什么（屏幕上那条列表与 `--json` 读同一句）。"""
        return f"{template_for(self.kind).label}｜{self.target_type}:{self.target_ref}"


@dataclass(frozen=True)
class Revision:
    id: str
    rule_id: str
    changed_by: str
    before: dict
    after: dict
    changed_at: datetime | None


def _to_rule(row: Mapping[str, object]) -> Rule:
    return Rule(
        id=str(row["id"]),
        user_id=str(row["user_id"]),
        name=str(row["name"]),
        kind=str(row["kind"]),
        enabled=bool(row["enabled"]),
        target_type=str(row["target_type"]),
        target_ref=str(row["target_ref"]),
        params=json.loads(str(row["params_json"] or "{}")),
        filters=json.loads(str(row["filters_json"] or "{}")),
        cooldown_min=int(row["cooldown_min"]),
        severity=str(row["severity"]),
        channel_ids=list(json.loads(str(row["channel_ids"] or "[]"))),
        account_id=row["account_id"],
        thesis_id=row["thesis_id"],
        condition_kind=str(row["condition_kind"]),
        created_at=row["created_at"],
        updated_at=row["updated_at"],
    )



def _snapshot(row: Rule) -> dict:
    """修订史里存的是**整份规则**，不是 diff（§4.2 要回答的是「当时那条线是多少」）。"""
    return {
        "name": row.name,
        "kind": row.kind,
        "params": row.params,
        "filters": row.filters,
        "severity": row.severity,
        "cooldown_min": row.cooldown_min,
        "channel_ids": row.channel_ids,
        "enabled": row.enabled,
        "target_type": row.target_type,
        "target_ref": row.target_ref,
        "account_id": row.account_id,
        "thesis_id": row.thesis_id,
    }


def _to_checked(row: Rule) -> dict:
    """把库里那一行还原成 `_validate` 的那个形状，只为了给 `update` 做一次「有没有实质变化」的比较。"""
    return {
        "name": row.name,
        "kind": row.kind,
        "params": row.params,
        "filters": row.filters,
        "severity": row.severity,
        "cooldown_min": row.cooldown_min,
        "channel_ids": row.channel_ids,
        "target_type": row.target_type,
        "target_ref": row.target_ref,
        "account_id": row.account_id,
        "thesis_id": row.thesis_id,
    }


def _deltas(before: dict, checked: dict) -> dict:
    """两个形状相同的字典之间，哪些字段真的变了。

    只比 `update` 改得到的那些字段：`enabled` 走 `set_enabled`，时间戳每次都在动，
    把它们算进「实质变化」就等于每条规则每天都有一条修订史。
    """
    return {key: value for key, value in checked.items() if before.get(key) != value}




class RuleRepo:
    def __init__(self, db: Database, *, clock: Clock = SYSTEM_CLOCK) -> None:
        self.db = db
        self.clock = clock

    # --- 写 -----------------------------------------------------------------------------

    def create(
        self,
        user_id: str,
        *,
        kind: str,
        name: str,
        target_type: str,
        target_ref: str,
        params: Mapping[str, object] | None = None,
        filters: Mapping[str, object] | None = None,
        account_id: str | None = None,
        thesis_id: str | None = None,
        severity: str | None = None,
        channel_ids: Sequence[str] = (),
        cooldown_min: int = 30,
        enabled: bool = True,
        condition_kind: str = CONDITION_KIND,
    ) -> Rule:
        checked = self._validate(
            user_id=user_id,
            name=name,
            kind=kind,
            target_type=target_type,
            target_ref=target_ref,
            params=params,
            filters=filters,
            account_id=account_id,
            thesis_id=thesis_id,
            severity=severity,
            channel_ids=channel_ids,
            cooldown_min=cooldown_min,
            condition_kind=condition_kind,
        )
        rule_id = new_id()
        now = self.clock.now_utc()
        self.db.execute(
            "INSERT INTO rules"
            " (id, user_id, account_id, name, enabled, target_type, target_ref, kind,"
            " condition_kind, params_json, filters_json, cooldown_min, severity, channel_ids,"
            " thesis_id, created_at, updated_at)"
            " VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
            [
                rule_id,
                checked["user_id"],
                checked["account_id"],
                checked["name"],
                bool(enabled),
                checked["target_type"],
                checked["target_ref"],
                checked["kind"],
                checked["condition_kind"],
                json.dumps(checked["params"], ensure_ascii=False),
                json.dumps(checked["filters"], ensure_ascii=False),
                checked["cooldown_min"],
                checked["severity"],
                json.dumps(checked["channel_ids"], ensure_ascii=False),
                checked["thesis_id"],
                now,
                now,
            ],
        )
        created = self.get(rule_id)
        assert created is not None
        return created

    #: 允许挂在整个组合上的 kind（现在一个都没有：组合级指标缺输入，U28）
    _PORTFOLIO_KINDS: tuple[str, ...] = ()

    def _validate(
        self,
        *,
        user_id: str,
        name: str,
        kind: str,
        target_type: str,
        target_ref: str,
        params: Mapping[str, object] | None,
        filters: Mapping[str, object] | None,
        account_id: str | None,
        thesis_id: str | None,
        severity: str | None,
        channel_ids: Sequence[str],
        cooldown_min: int,
        condition_kind: str = CONDITION_KIND,
    ) -> dict:
        """`create` 与 `update` 共用这一套校验。

        抽出来不是为了少写几行：`update` 必须把**旧值与新值合并后**的那一份重走一遍创建时
        的全部判据，而两处各写一遍是这个文件最容易分叉的地方——分叉的后果长成「创建时不许
        的东西，改的时候改进去了」。返回校验过的同名字典，调用方只管落库。
        """
        if not user_id:
            raise ValidationError("规则必须属于一个用户：没有归属就没有路由")
        label = (name or "").strip()
        if not label:
            raise ValidationError("规则要有个名字：`sams alerts` 里那一条要说清是谁在响")
        built = template_for(kind)  # 未知 kind 在这里就拒，顺带把名单的回显给出去
        if condition_kind != CONDITION_KIND:
            raise ValidationError(
                f"condition_kind 只能是 {CONDITION_KIND!r}：受限表达式是 M5 的事（§10.4），"
                "现在收进来只会得到一条没人求值的规则"
            )
        if target_type not in TARGET_TYPES:
            raise ValidationError(
                f"未知对象类型 target_type={target_type!r}：只有 {', '.join(TARGET_TYPES)}"
            )
        if target_type not in built.targets:
            allowed = "/".join(built.targets)
            raise ValidationError(
                f"{kind} 不能挂在 {target_type} 上：这一种只认 {allowed}。"
                "名单收在模板表里而不是放开全部五种，因为 `expand()` 要能对每一种给出确定的"
                "展开方式——挂错对象的规则不会报错，只会静默地不响（§1 那张表的第一行）"
            )
        self._require_target_shape(target_type, target_ref)
        if built.needs_position and not account_id:
            raise ValidationError(
                f"{kind}（{built.label}）必须挂在某个账户上：去重键含 account_id，"
                "缺了它，同一只票在两个账户里的破位会互相吞（§10.1）"
            )
        if target_type == "portfolio" and not account_id:
            raise ValidationError("组合类规则必须说明是哪个账户的组合")
        if kind not in self._PORTFOLIO_KINDS and target_type == "portfolio":
            raise ValidationError(
                f"{kind} 不支持挂在整个组合上：这一层没有组合级指标的输入（U28）"
            )
        if built.needs_thesis and not thesis_id:
            raise ValidationError(f"{kind} 必须挂在一条论上：它读的是那条论的价位与分项")
        if target_type == "thesis" and thesis_id is not None and target_ref != thesis_id:
            raise ValidationError(
                "target_type=thesis 时 target_ref 就是那条论的 id："
                "两者不一致会让 expand() 取到一条论而校验另一条"
            )
        self._require_thesis(user_id, thesis_id)
        checked_params = validate_params(kind, params)
        checked_filters = validate_filters(filters)
        level = built.severity if severity is None else severity
        if level not in SEVERITIES:
            raise ValidationError(f"未知严重级别 severity={level!r}：只有 {list(SEVERITIES)}")
        if int(cooldown_min) < 0:
            raise ValidationError(f"cooldown_min 不能为负（收到 {cooldown_min}）")
        return {
            "user_id": user_id,
            "name": label,
            "kind": kind,
            "target_type": target_type,
            "target_ref": target_ref,
            "params": checked_params,
            "filters": checked_filters,
            "severity": level,
            "cooldown_min": int(cooldown_min),
            "channel_ids": list(channel_ids),
            "account_id": account_id,
            "thesis_id": thesis_id,
            "condition_kind": condition_kind,
        }

    def update(
        self,
        rule_id: str,
        *,
        changed_by: str,
        name: str | None = None,
        kind: str | None = None,
        params: Mapping[str, object] | None = None,
        filters: Mapping[str, object] | None = None,
        severity: str | None = None,
        channel_ids: Sequence[str] | None = None,
        cooldown_min: int | None = None,
        target_type: str | None = None,
        target_ref: str | None = None,
    ) -> Rule:
        """一次改动写一条修订史（§4.2）。没有实质变化 ⇒ 不写。"""
        before = self._require(rule_id)
        patch = {
            key: value
            for key, value in {
                "name": name,
                "kind": kind,
                "params": params,
                "filters": filters,
                "severity": severity,
                "channel_ids": channel_ids,
                "cooldown_min": cooldown_min,
                "target_type": target_type,
                "target_ref": target_ref,
            }.items()
            if value is not None
        }
        if not patch:
            raise ValidationError("什么都没要改：`rule edit` 至少给一个参数")
        # 用新值重走一遍创建时的那整套校验，所以「改 kind 而旧参数不合」在这里就红
        merged = {
            "user_id": before.user_id,
            "name": patch.get("name", before.name),
            "kind": patch.get("kind", before.kind),
            "target_type": patch.get("target_type", before.target_type),
            "target_ref": patch.get("target_ref", before.target_ref),
            "params": patch.get("params", before.params),
            "filters": patch.get("filters", before.filters),
            "severity": patch.get("severity", before.severity),
            "cooldown_min": patch.get("cooldown_min", before.cooldown_min),
            "account_id": before.account_id,
            "thesis_id": before.thesis_id,
            "channel_ids": patch.get("channel_ids", before.channel_ids),
        }
        if kind is not None and params is None:
            # 换 kind 而不给新参数：旧参数对新 kind 多半是野键，让它在这里就红，
            # 而不是带着一个没人读的键进库（屏幕上那条规则于是显示着一个不生效的数）
            raise ValidationError(
                f"改成 {kind} 必须同时给新的 params：旧的那些属于 {before.kind}，"
                "留着就是屏幕上一个不生效的键"
            )
        checked = self._validate(**merged)
        if not _deltas(_to_checked(before), checked):
            # 一次「改成同样的值」不在修订史里留一行：§4.2 那张表要能回答「这条线改过几次」，
            # 把空改动算进去就是在数橡皮擦的印子
            return before
        self.db.execute(
            "UPDATE rules SET name = ?, kind = ?, target_type = ?, target_ref = ?,"
            " params_json = ?, filters_json = ?, severity = ?, cooldown_min = ?,"
            " channel_ids = ?, updated_at = ? WHERE id = ?",
            [
                checked["name"],
                checked["kind"],
                checked["target_type"],
                checked["target_ref"],
                json.dumps(checked["params"], ensure_ascii=False),
                json.dumps(checked["filters"], ensure_ascii=False),
                checked["severity"],
                checked["cooldown_min"],
                json.dumps(checked["channel_ids"], ensure_ascii=False),
                self.clock.now_utc(),
                before.id,
            ],
        )
        after = self.get(before.id)
        assert after is not None
        self.db.execute(
            "INSERT INTO rule_revisions (id, rule_id, changed_by, before_json, after_json,"
            " changed_at) VALUES (?, ?, ?, ?, ?, ?)",
            [
                new_id(),
                before.id,
                changed_by,
                json.dumps(_snapshot(before), ensure_ascii=False),
                json.dumps(_snapshot(after), ensure_ascii=False),
                self.clock.now_utc(),
            ],
        )
        return after

    def set_enabled(self, rule_id: str, enabled: bool, *, user_id: str | None = None) -> Rule:
        row = self._require(rule_id, user_id=user_id)
        self.db.execute(
            "UPDATE rules SET enabled = ?, updated_at = ? WHERE id = ?",
            [bool(enabled), self.clock.now_utc(), row.id],
        )
        return self._require(rule_id, user_id=user_id)

    def remove(self, rule_id: str, *, user_id: str | None = None) -> bool:
        row = self._require(rule_id, user_id=user_id)
        if row.thesis_id:
            raise ValidationError(
                f"规则 {row.name} 是从一条观点派生出来的，不能删除，只能 `sams rule disable`："
                "「悄悄关掉止损提醒」必须留下一条能查到的记录（§9.2）"
            )
        self.db.execute("DELETE FROM rule_revisions WHERE rule_id = ?", [row.id])
        self.db.execute("DELETE FROM rules WHERE id = ?", [row.id])
        return True

    # --- 读 -----------------------------------------------------------------------------

    def get(self, rule_id: str, *, user_id: str | None = None) -> Rule | None:
        sql = f"SELECT {_COLUMNS} FROM rules WHERE id = ?"
        params: list[object] = [rule_id]
        if user_id is not None:
            sql += " AND user_id = ?"
            params.append(user_id)
        rows = self.db.query(sql, params)
        return _to_rule(rows.to_dicts()[0]) if rows.height else None

    def list_for(self, user_id: str, *, enabled_only: bool = False) -> list[Rule]:
        sql = f"SELECT {_COLUMNS} FROM rules WHERE user_id = ?"
        params: list[object] = [user_id]
        if enabled_only:
            sql += " AND enabled = TRUE"
        sql += " ORDER BY created_at, id"
        return [_to_rule(row) for row in self.db.query(sql, params).to_dicts()]

    def by_thesis(self, thesis_id: str) -> list[Rule]:
        rows = self.db.query(
            f"SELECT {_COLUMNS} FROM rules WHERE thesis_id = ? ORDER BY created_at, id",
            [thesis_id],
        )
        return [_to_rule(row) for row in rows.to_dicts()]

    def revisions(self, rule_id: str) -> list[Revision]:
        rows = self.db.query(
            "SELECT id, rule_id, changed_by, before_json, after_json, changed_at"
            " FROM rule_revisions WHERE rule_id = ? ORDER BY changed_at, id",
            [rule_id],
        )
        return [
            Revision(
                id=str(row["id"]),
                rule_id=str(row["rule_id"]),
                changed_by=str(row["changed_by"]),
                before=json.loads(str(row["before_json"] or "{}")),
                after=json.loads(str(row["after_json"] or "{}")),
                changed_at=row["changed_at"],
            )
            for row in rows.to_dicts()
        ]

    def counts(self, user_id: str) -> dict[str, int]:
        rows = self.db.query(
            "SELECT count(*) total, coalesce(sum(CASE WHEN enabled THEN 1 ELSE 0 END), 0) on"
            " FROM rules WHERE user_id = ?",
            [user_id],
        ).to_dicts()[0]
        return {"total": int(rows["total"]), "enabled": int(rows["on"])}

    # --- 内部 ---------------------------------------------------------------------------

    def _require(self, rule_id: str, *, user_id: str | None = None) -> Rule:
        row = self.get(rule_id, user_id=user_id)
        if row is None:
            raise StorageError(f"规则 {rule_id} 不存在" + ("" if user_id is None else "（或不属于这个用户）"))
        return row

    def _require_target_shape(self, target_type: str, target_ref: str) -> None:
        ref = (target_ref or "").strip()
        if not ref:
            raise ValidationError(
                f"target_ref 不能是空的：{target_type} 类型的规则要能展开成一个具体对象"
                "（空引用会展开成零个目标，那条规则从此静默不响）"
            )
        if target_type in _WILDCARD_TARGETS:
            if ref != "*":
                raise ValidationError(
                    f"target_type={target_type} 时 target_ref 要写 `*`（整个集合），收到 {ref!r}"
                )
            return
        if target_type == "symbol" and "/" not in ref:
            raise ValidationError(
                f"target_ref 要写成 市场/代码（例如 A/601088），收到 {ref!r}："
                "只有代码时 A 股与港股会撞同一个键"
            )

    def _require_thesis(self, user_id: str, thesis_id: str | None) -> None:
        if thesis_id is None:
            return
        from sams.storage.repos.theses import ThesisRepo

        if ThesisRepo(self.db).get(user_id, thesis_id) is None:
            raise ValidationError(
                f"观点 {thesis_id} 不存在（或不属于这个用户）：一条读不到价位的规则"
                "会永远显示成「没触发」"
            )
```

```python
        self,
        rule_id: str,
        market: str,
        code: str,
        *,

        而 `EXISTS` 只回答有没有——「有没有」决定不了要不要穿过冷却。一次问清还省掉

            f"SELECT {_ALERT_COLUMNS} FROM alerts"
            " WHERE rule_id = ? AND market = ? AND code = ?"
            " AND account_id IS NOT DISTINCT FROM ?"
            " ORDER BY triggered_at DESC, id DESC LIMIT 1",

        )
```

```python
    def set_baseline(
        self,
        user_id: str,
        thesis_id: str,
        *,
        score: float,
        items: Mapping[str, float],
        on: date,
        now: datetime,
    ) -> Thesis:
        """写下复检的基准（0016）。只有 `recheck` 在**还没有基线**时调它，所以没有「改基线」的入口。

        `score=None` 会被拒：那不是「0 分」而是「这一趟没算出分」，把它写成基线等于给一条
        论钉死一个永远达不到的基准——此后每趟掉档都是它的错。
        归档那条也拒，理由与 `set_levels` 同一条：`archived` 是终点，改它是在重写历史。
        """
        if score is None:
            raise ValidationError("基线分数不能是空的：那是「没比过」，不是「最差」")
        if not 0.0 <= float(score) <= 100.0:
            raise ValidationError(f"基线分数要在 0~100（收到 {score}）：分项分就是这个刻度")
        current = self.require(user_id, thesis_id)
        if current.status == ARCHIVED:
            raise StorageError(
                f"{thesis_id} 已经归档：基线是「建仓时那一眼」，归档的论不再有那一眼"
            )
        cleaned = {str(key): float(value) for key, value in items.items()}
        self.db.execute(
            "UPDATE theses SET baseline_score = ?, baseline_items = ?, baseline_on = ?,"
            " updated_at = ? WHERE user_id = ? AND id = ?",
            [
                float(score),
                json.dumps(cleaned, ensure_ascii=False, sort_keys=True),
                on,
                now,
                current.user_id,
                current.id,
            ],
        )
        found = self.get(user_id, thesis_id)
        assert found is not None  # 同一个库里刚 UPDATE 过
        return found
```

```python
库里的指标都是**在后复权序列上**算的（跨除权日才可比），而用户看的是现价、交易的是现价，
阈值也是按现价填的。所以每一路指标出门前都要乘一个 `现价 ÷ 当日后复权收盘`。

这个文件存在的理由是「同一件外套不能有两件」：`services/valuation.py` 用它合成结论，
`services/rules/` 用它判止损。两边各写一遍的后果是除权日只有一侧折回，于是那条止损在
分红当天报「已跌破」——§10.2 把它列为强制验收用例，就是这个原因。

因子必须来自**它自己那条序列**（周线用周线的当日收盘与当日后复权收盘）：后复权的绝对

from typing import Any

import polars as pl


def fold(price: float | None, hfq_last: float | None) -> float | None:
    """后复权 → 现价的换算系数。两个数齐了才有它，否则 None（合成侧自己会拒）。"""
    if price is None or hfq_last is None or hfq_last <= 0 or price <= 0:
        return None
    return price / hfq_last


def fold_to_price_basis(value: float | None, factor: float | None) -> float | None:
    if value is None or factor is None:
        return None
    return value * factor


def last(table: pl.DataFrame, column: str) -> Any:
    if table.height == 0 or column not in table.columns:
        return None
    return table[column][-1]


def before_last(table: pl.DataFrame, column: str) -> Any:
    if table.height < 2 or column not in table.columns:
        return None
    return table[column][-2]


def window_high(table: pl.DataFrame, bars: int) -> float | None:
    """窗口内最高的那根后复权收盘（**还没**折回现价口径：调用方拿自己那条序列的因子折它）。"""
    if table.height == 0 or bars <= 0 or "close_hfq" not in table.columns:
        return None
    return table["close_hfq"].tail(bars).max()


def pct_change(table: pl.DataFrame, column: str) -> float | None:
    """最后一根相对上一根的涨跌幅（在后复权口径里算：跨除权日时裸价那个差是分红）。"""
    now, prior = last(table, column), before_last(table, column)
    if now is None or prior is None or prior <= 0:
        return None
    return now / prior - 1.0


def weekly_line(weekly_table: pl.DataFrame) -> float | None:
    """周 MA20 折回现价口径：用它**自己那条序列**的当日因子，不借日线的。"""
    return fold_to_price_basis(
        last(weekly_table, "ma20"),
        fold(last(weekly_table, "close"), last(weekly_table, "close_hfq")),
    )
```

```python
"""规则引擎唯一的取数处（spec §10「输入」那一列）。

拆成两个动作：`expand` 回答「这条规则覆盖哪些对象」，`read` 回答「那个对象此刻是什么数」。
分开的理由是冷却：去重键里有 `account_id`，所以展开必须带着账户出门。

这一层是全套规则里**唯一**允许碰 IO 的地方。模板因此是纯函数（T-7 起），除权日那种错
在手搓的 `Snapshot` 上就能复现，不必等网络。

不认识的 target_type 一律抛，不返回空列表：空列表在屏幕上长成「这条规则没触发」，
而它真实的意思是「这条规则谁也没看」。
"""

from __future__ import annotations

from dataclasses import dataclass
from datetime import date, timedelta

import polars as pl

from sams.core.codes import canonical_code, canonical_market
from sams.core.errors import ValidationError
from sams.services._fold import fold, fold_to_price_basis, last, window_high
from sams.storage.repos.ledger import Account, Position, SimAccountRepo, SimOrderRepo
from sams.storage.repos.theses import Thesis, ThesisRepo

#: 日线一次取多少天：盖住 MA60（60 个交易日）与一段正常持有期。
#: 与 `valuation` 的窗口无关，所以它自己算一次：那边只带它合成结论要的那几路出门。
DAILY_LOOKBACK_DAYS = 400

#: 持仓不足这么多根日 K 时，「持仓期最高价」没有意义（第一根就是最高价，回撤恒为 0）。
TRAILING_MIN_BARS = 3

#: MA60 要哪一列：`indicators=("ma",)` 产出 ma5/ma10/ma20/ma60/ma120/ma250
_MA_COLUMN = "ma60"


@dataclass(frozen=True)
class Target:
    """一趟求值里的一个对象。`user_id` 也在里面：展开出来的一切都必须说清是谁的。"""

    user_id: str
    market: str
    code: str
    account_id: str | None = None
    thesis_id: str | None = None


@dataclass(frozen=True)
class Snapshot:
    """一个对象在一次求值里的全部事实，**现价口径 + 标的币种**。

    每个数与它的 `*_on` 同进同出：一条「跌破止损」必须说得出这个价是哪天的。
    所有 `None` 都是「没有这个数」而不是 0——0 在阈值语言里是一个能触发止损的值。
    """

    market: str
    code: str
    #: 显示名（`symbols` 里那一列；读不到就用代码本身，屏幕上不能是空的）
    name: str = ""
    currency: str = ""
    report_currency: str = ""
    account_id: str | None = None
    account_name: str = ""
    thesis_id: str | None = None
    #: 现价（过闸日线的裸收盘）与它属于哪天
    price: float | None = None
    price_on: date | None = None
    price_age_days: int | None = None
    #: 当日开盘与前收盘：`urgent`（跳空低开破位）与 `price.cross_*` 靠这两个数。
    #: 库里只有日线，所以开盘价来自 `BarRepo`，不是快照流（§3 的裁剪）
    day_open: float | None = None
    prev_close: float | None = None
    #: 持仓（None ⇒ 这个目标此刻没有持仓，持仓类模板一律不判）
    qty: float | None = None
    avg_cost: float | None = None
    opened_on: date | None = None
    holding_days: int | None = None
    #: 持仓期最高价，折回现价口径。不足 `TRAILING_MIN_BARS` 根 ⇒ None
    holding_high: float | None = None
    #: 折回现价口径的技术位
    weekly_ma20: float | None = None
    daily_ma60: float | None = None
    atr: float | None = None
    #: 论上那几列 + 本次合成的结论
    stop_line: float | None = None
    target_price: float | None = None
    odds: float | None = None
    score: float | None = None
    items: tuple[tuple[str, float], ...] = ()
    #: 最近一期财报的披露日（`scheduled.reevaluate` 的输入）
    disclosed_on: date | None = None
    #: 保证金账户：`notes` 据此说「爆仓线可能先到」
    margin_enabled: bool = False
    #: 这一路缺了什么（进告警正文、`--explain` 与 `--json`）
    missing: tuple[str, ...] = ()


class RuleData:
    """把八个仓库/服务包成两个动作。构造参数全是 `Container` 上已有的字段。"""

    def __init__(
        self,
        *,
        valuation,
        analysis,
        bars,
        symbols,
        accounts: SimAccountRepo,
        ledger: SimOrderRepo,
        theses: ThesisRepo,
        watchlists,
        settings,
    ) -> None:
        self.valuation = valuation
        self.analysis = analysis
        self.bars = bars
        self.symbols = symbols
        self.accounts = accounts
        self.ledger = ledger
        self.theses = theses
        self.watchlists = watchlists
        self.settings = settings

    # --- 展开 ---------------------------------------------------------------------------

    def expand(self, rule) -> list[Target]:
        """一条规则 → 一组对象。`enabled` 与冷却由调用方管，这里只管形状。"""
        kind = rule.target_type
        if kind == "symbol":
            market, _, code = rule.target_ref.partition("/")
            normalized = canonical_market(market)
            return [
                Target(
                    rule.user_id,
                    normalized,
                    canonical_code(normalized, code),
                    rule.account_id,
                    rule.thesis_id,
                )
            ]
        if kind == "watchlist":
            return [
                Target(rule.user_id, market, code, rule.account_id, rule.thesis_id)
                for market, code in self.watchlists.codes(rule.user_id)
            ]
        if kind == "position":
            if rule.account_id is None:
                raise ValidationError(
                    f"规则 {rule.name} 是持仓类却没有账户：去重键含 account_id，"
                    "缺了它同一只票在两个账户里的破位会互相吞（§10.1）"
                )
            return [
                Target(rule.user_id, row.market, row.code, rule.account_id, rule.thesis_id)
                for row in self.holdings(rule.account_id)
            ]
        if kind == "thesis":
            thesis = self._thesis_of_rule(rule)
            if thesis is None:
                return []
            return [Target(rule.user_id, thesis.market, thesis.code, rule.account_id, thesis.id)]
        raise ValidationError(
            f"target_type={kind} 这一层没有展开方式：组合级规则要的是每日组合快照（U28），"
            "而库里还没有那张表"
        )

    def holdings(self, account_id: str) -> list[Position]:
        """当前持仓（不含已清仓的 0 股行）。一趟里同一个账户只读一次由引擎保证：
        它先调这里拿表，再把每一行交给 `read(..., position=...)`。"""
        return [row for row in self.ledger.positions(account_id) if row.qty > 0]

    def thesis_for(self, target: Target) -> Thesis | None:
        if target.thesis_id is None:
            return None
        return self.theses.get(target.user_id, target.thesis_id)

    def _thesis_of_rule(self, rule) -> Thesis | None:
        return self.theses.get(rule.user_id, rule.thesis_id or rule.target_ref)

    # --- 读取 ---------------------------------------------------------------------------

    def read(
        self,
        target: Target,
        *,
        as_of: date,
        position: Position | None = None,
    ) -> Snapshot:
        """装配一个对象此刻的全部数。三路读取各有各的理由（见模块开头）。

        `position` 是引擎从 `holdings()` 里带来的那一行：带着它就不必读第二次，
        而两次读之间规则可以被改，那样算出来的成本与屏幕上那一条不是同一个数。
        """
        thesis = self.thesis_for(target)
        valuation = self.valuation.read(
            target.market,
            target.code,
            as_of=as_of,
            style=thesis.style if thesis is not None else "value",
        )
        daily = self.analysis.series(
            target.market,
            target.code,
            start=as_of - timedelta(days=DAILY_LOOKBACK_DAYS),
            end=as_of,
            indicators=("ma",),
        )
        account = self._account(target)
        missing: list[str] = []
        if valuation.price is None:
            missing.append("没有过闸的现价：这一趟不判任何价格类条件")
        return Snapshot(
            market=target.market,
            code=target.code,
            name=self._name(target),
            currency=self._currency(target, position),
            report_currency=(
                account.report_currency
                if account is not None
                else self.settings.report_currency
            ),
            account_id=target.account_id,
            account_name=account.name if account is not None else "",

            daily_ma60=_fold_line(daily.table, _MA_COLUMN, valuation.price),
            atr=valuation.atr,
            stop_line=_stop_line(thesis, valuation),

            odds=valuation.plan.odds.value,

        if target.account_id is None:
            return None

    def _currency(self, target: Target, position: Position | None) -> str:
        """标的币种：有持仓就用账本那一列，没有才退回市场配置。

        顺序反过来的话，一个把 `symbols.currency` 写歪的旧行会让阈值带上错误的币种后缀
        （§5.4 规则 3 禁止未标注币种的金额，而**标错**比不标更难查）。
        """
        if position is not None:
            return position.currency
        cfg = self.settings.markets.get(target.market)
        return cfg.currency if cfg is not None else ""

    def _day_open(self, target: Target, as_of: date) -> float | None:
        """当日开盘：库里只有不复权日线，裸价**就是**现价口径（不折）。"""
        frame = self.bars.load(target.market, [target.code], start=as_of, end=as_of)
        if frame.height == 0:
            return None
        value = frame["open"][0]
        return None if value is None else float(value)

    def _prev_close(self, table: pl.DataFrame, price: float | None) -> float | None:
        """前收盘折回现价口径：跨除权日时裸价那个「昨天」不是今天可比的那个「昨天」。"""
        if table.height < 2 or "close_hfq" not in table.columns:
            return None
        return fold_to_price_basis(float(table["close_hfq"][-2]), fold(price, last(table, "close_hfq")))

def _fold_line(table: pl.DataFrame, column: str, price: float | None) -> float | None:
    """把后复权口径的一条指标折到现价口径：因子来自**这条**日线序列的当日两个收盘。"""
    return fold_to_price_basis(last(table, column), fold(price, last(table, "close_hfq")))


def _holding_high(
    table: pl.DataFrame, price: float | None, position: Position | None, as_of: date
) -> float | None:
    """持仓期最高价（现价口径）。没有持仓、没有建仓时刻、或不足三根 ⇒ None（见常量注释）。"""
    if position is None or position.open_ts is None or table.height == 0:
        return None
    window = table.filter(pl.col("date") >= position.open_ts.date())
    if window.height < TRAILING_MIN_BARS:
        return None
    factor = fold(price, last(table, "close_hfq"))
    return fold_to_price_basis(window_high(window, window.height), factor)


def _stop_line(thesis: Thesis | None, valuation) -> float | None:
    """止损线优先用**论上那一列**（用户确认过的数），没有才退回本次合成的那一条。

    顺序反过来的话，用户手工把线抬到成本（`stop.breakeven` 之后常见）会被下一次自动
    合成覆盖——屏幕上那条线就不是他填的那一条了。
    """
    if thesis is not None and thesis.stop_price is not None:
        return thesis.stop_price
    return valuation.plan.stop.low if valuation.plan.stop.ok else None


def _date_of(moment) -> date | None:
    return None if moment is None else moment.date()


def _holding_days(position: Position | None, as_of: date) -> int | None:
    if position is None or position.open_ts is None:
        return None
    return max(0, (as_of - position.open_ts.date()).days)
```

```python
"""每个 kind 一个纯函数：给一份 `Snapshot` 与那几条参数，判一次（spec §10.3）。

`Outcome` 而不是 `Verdict | None`：**「没触发」与「判不了」是两句话**。前者不该有任何
输出，后者必须给出那句话——否则一条因为缺数据而从没响过的规则，在屏幕上与一条
工作正常的规则长得一模一样（§1 那张表的最后一行）。

所有阈值都在**现价口径 + 标的币种**里比（§5.4 规则 3）：折回因子是 T-6 乘好的，
这里再乘一次就是两件外套，除权日会只有一侧折回。
"""

from __future__ import annotations

from collections.abc import Callable, Mapping
from dataclasses import dataclass

from sams.core.rules import HIT, PRE, URGENT, Verdict
from sams.services.rules.snapshot import Snapshot

#: 「快到了」那一档有多近：再跌 2% 到线就报 `pre`（§10.2 举例的那个刻度）。
#: 写成一处而不是每个模板的参数：九种止损各配一个 `pre_band`，用户要回答一个他自己
#: 也说不清的数，而配出九个值就是没有值。
PRE_BAND = 0.02


@dataclass(frozen=True)
class Ask:
    """一次求值的输入：谁的哪个对象、此刻的数、这条规则的参数。"""

    snapshot: Snapshot
    params: Mapping[str, object]
    #: 这条规则挂着的那条论（若有）。模板读它的价位与状态时**只**从这里读，不自己去查库：
    #: `Snapshot` 已经查过一次，两次之间规则还能被改
    thesis: object | None = None


@dataclass(frozen=True)
class Outcome:
    """一个模板的一次输出。`hit` 为 None 时 `why_not` 是那句话，或者那句空。"""

    hit: Verdict | None = None
    why_not: str = ""


def money(value: float | None, currency: str) -> str:
    """阈值与现价的措辞：数后面永远跟着币种（§5.4 规则 3）。

    金额类阈值不允许不带币种，而 A 股是元、美股是美元——屏幕上写「止损 100」的那条规则，
    用户在手机上会按另一种货币去理解它。
    """
    if value is None:
        return "未知"
    return f"{value:.2f} {currency or '元'}"


def stop_stage(
    snapshot: Snapshot, line: float, *, pre_band: float = PRE_BAND
) -> str | None:
    """三档判定。顺序不能调：先看跳空，再看是否已破，最后才看「快到了」。

    `urgent` 要求**前收盘在线上方**而**开盘在线下方**——只有这种形状才是「一开盘就没机会」。
    只看开盘的话，一条早就破了的线每趟都会升格成 urgent，那一档的意义被用光。
    """
    price = snapshot.price
    if price is None:
        return None
    if (
        snapshot.day_open is not None
        and snapshot.prev_close is not None
        and snapshot.day_open < line
        and snapshot.prev_close >= line
    ):
        return URGENT
    if price < line:
        return HIT
    if price < line * (1.0 + pre_band):
        return PRE
    return None


def _no_price(snapshot: Snapshot) -> str:
    return (
        f"没有 {snapshot.market}/{snapshot.code} 过闸的现价：这一趟不判任何价格类条件"
        "（§10.1 的新鲜度过滤器拦掉的就是这种读数）"
    )


def _gap_note(snapshot: Snapshot, line: float, stage: str) -> str:
    """`urgent` 那句话要把「开盘 vs 前收盘」两个数一起说出来：只报现价的话，
    读的人看不出这是跳空而不是慢慢跌过去的。"""
    if stage != URGENT:
        return ""
    return (
        f"；开盘 {money(snapshot.day_open, snapshot.currency)} 直接在线 "
        f"{money(line, snapshot.currency)} 下方（前收盘 "
        f"{money(snapshot.prev_close, snapshot.currency)}），这一跳不是盘中跌过去的"
    )


def _hit(snapshot: Snapshot, line: float, stage: str, why: str) -> Outcome:
    return Outcome(
        Verdict(
            stage=stage,
            value=snapshot.price,
            threshold=line,
            value_text=money(snapshot.price, snapshot.currency),
            threshold_text=money(line, snapshot.currency),
            why=why + _gap_note(snapshot, line, stage),
        )
    )


def stop_fixed(ask: Ask) -> Outcome:
    """`stop.fixed`：跌破绝对价即报。线就是用户填的那个数（现价口径、标的币种）。"""
    snapshot = ask.snapshot
    if snapshot.price is None:
        return Outcome(why_not=_no_price(snapshot))
    line = float(ask.params["price"])
    stage = stop_stage(snapshot, line)
    if stage is None:
        return Outcome()
    return _hit(
        snapshot, line, stage, f"绝对价止损线 {money(line, snapshot.currency)}"
    )


def stop_pct(ask: Ask) -> Outcome:
    """`stop.pct`：成本下浮 x%。没有持仓就没有成本，这一条不判而不是判成 0 成本。"""
    snapshot = ask.snapshot
    if snapshot.price is None:
        return Outcome(why_not=_no_price(snapshot))
    if snapshot.avg_cost is None or snapshot.avg_cost <= 0:
        return Outcome(
            why_not=f"这一笔在账户 {snapshot.account_id} 里没有成本：`stop.pct` 的线"
            "由成本算出，缺了它就没有线"
        )
    pct = float(ask.params["pct"])
    line = snapshot.avg_cost * (1.0 - pct)
    stage = stop_stage(snapshot, line)
    if stage is None:
        return Outcome()
    return _hit(
        snapshot,
        line,
        stage,
        f"成本 {money(snapshot.avg_cost, snapshot.currency)} 下浮 {pct:.1%}"
        f" ⇒ 线 {money(line, snapshot.currency)}",
    )


def stop_trailing(ask: Ask) -> Outcome:
    """`stop.trailing`：持仓期最高价回撤 x%。最高价来自 T-6，已是现价口径。"""
    snapshot = ask.snapshot
    if snapshot.price is None:
        return Outcome(why_not=_no_price(snapshot))
    if snapshot.holding_high is None:
        return Outcome(
            why_not="没有可用的持仓期最高价（持仓不足三根日 K 时它没有意义）："
            "拿现价凑会让回撤恒为 0，那条线贴在现价上方，第一次呼吸就报止损"
        )
    pct = float(ask.params["pct"])
    line = snapshot.holding_high * (1.0 - pct)
    stage = stop_stage(snapshot, line)
    if stage is None:
        return Outcome()
    return _hit(
        snapshot,
        line,
        stage,
        f"持仓期最高价 {money(snapshot.holding_high, snapshot.currency)}"
        f" 回撤 {pct:.1%} ⇒ 线 {money(line, snapshot.currency)}",
    )


TABLE: dict[str, Callable[[Ask], Outcome]] = {
    "stop.fixed": stop_fixed,
    "stop.pct": stop_pct,
    "stop.trailing": stop_trailing,
}
```

```python
def stop_atr(ask: Ask) -> Outcome:
    """`stop.atr`：成本 − 倍数×ATR14。ATR 由 T-6 折回现价口径，这里只做算术。"""
    snapshot = ask.snapshot
    if snapshot.price is None:
        return Outcome(why_not=_no_price(snapshot))
    if snapshot.avg_cost is None or snapshot.avg_cost <= 0:
        return Outcome(why_not="没有成本就没有这条线：`stop.atr` 是从成本往下量倍数")
    if snapshot.atr is None:
        return Outcome(
            why_not="这一路没有 ATR14（日 K 不足 14 根，或那几根没过数据闸）："
            "把它当 0 会让线正好贴在成本上，现价低一分都报止损"
        )
    multiple = float(ask.params["multiple"])
    line = snapshot.avg_cost - multiple * snapshot.atr
    if line <= 0:
        return Outcome(
            why_not=f"倍数 {multiple:g} 把线算到了 {money(line, snapshot.currency)}："
            "一条在 0 以下的线永远不会触发，这条规则等于没写"
        )
    stage = stop_stage(snapshot, line)
    if stage is None:
        return Outcome()
    return _hit(
        snapshot,
        line,
        stage,
        f"成本 {money(snapshot.avg_cost, snapshot.currency)} − {multiple:g}×ATR14"
        f"（{money(snapshot.atr, snapshot.currency)}，已从后复权折回现价口径）"
        f" ⇒ 线 {money(line, snapshot.currency)}",
    )


#: `basis` 那两个取值 → (取 `Snapshot` 的哪个字段, 那句话里的名字)
#: 名字写在这里而不是拼出来：「日 MA60」是给人读的词，字段名是给代码读的，
#: 把 `daily_ma60` 直接上屏等于让用户去猜那是什么意思。
_MA_LINES = {"weekly_ma20": ("weekly_ma20", "周 MA20"), "daily_ma60": ("daily_ma60", "日 MA60")}


def stop_ma(ask: Ask) -> Outcome:
    """`stop.ma`：跌破均线。两条线都在 T-6 折回过，用哪一条由参数说。"""
    snapshot = ask.snapshot
    if snapshot.price is None:
        return Outcome(why_not=_no_price(snapshot))
    field, label = _MA_LINES[str(ask.params["basis"])]
    line = getattr(snapshot, field)
    if line is None:
        return Outcome(
            why_not=f"没有 {label}：这一路的窗口不够长，或那几根日 K 没过数据闸"
        )
    stage = stop_stage(snapshot, line)
    if stage is None:
        return Outcome()
    return _hit(
        snapshot, line, stage, f"现价跌破 {label} {money(line, snapshot.currency)}"
    )


def stop_breakeven(ask: Ask) -> Outcome:
    """`stop.breakeven`：浮盈曾经到过 x% 之后，把线抬到成本。

    触发判据是**持仓期最高价**而不是今天的现价（上面那枚测试的理由）：这一条的意义就是
    「已经赚过，别把利润全还回去」，而赚过的那一刻是唯一可查的事实。
    线抬到成本 ⇒ 现价只要低于成本就 `hit`，正是字面意思。
    """
    snapshot = ask.snapshot
    if snapshot.price is None:
        return Outcome(why_not=_no_price(snapshot))
    if snapshot.avg_cost is None or snapshot.avg_cost <= 0:
        return Outcome(why_not="保本止损要把线抬到成本，而这一笔没有成本可读")
    if snapshot.holding_high is None:
        return Outcome(
            why_not="没有持仓期最高价：判不出「曾经到过 x%」，宁可不报也不猜"
        )
    trigger = float(ask.params["trigger_pct"])
    reached = snapshot.holding_high / snapshot.avg_cost - 1.0
    if reached < trigger:
        return Outcome()
    line = snapshot.avg_cost
    stage = stop_stage(snapshot, line)
    if stage is None:
        return Outcome()
    return _hit(
        snapshot,
        line,
        stage,
        f"持仓期最高 {money(snapshot.holding_high, snapshot.currency)}"
        f"（成本上方 {reached:.1%}，已过 {trigger:.1%}）⇒ 线已抬到成本 "
        f"{money(line, snapshot.currency)}",
    )
```
